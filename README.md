# 錄音轉文字（meeting-transcriber-zh）

會議錄音 → 逐字稿 → 專有名詞校正 → 會議記錄（md + PDF），一個 Windows 視窗程式完成。

- 語音辨識在**本機**執行（[faster-whisper](https://github.com/SYSTRAN/faster-whisper)，CPU 即可），錄音不會上傳。
- 專有名詞校正畫面：AI 列出疑似辨識錯誤的詞，可**播放該時間點原音**再決定，確認過的詞累積成對照表。
- 會議記錄由你自己訂閱的 **Claude Code** 或 **Codex** 命令列工具撰寫，使用訂閱額度，不需要 API 金鑰。
- 繁體中文為主，也支援英文、日文、自動偵測、多語混合。

> 本專案只提供原始碼，不提供打包好的執行檔。請依「**十一、從原始碼執行／自行打包**」安裝 Python 套件後執行 `python app.py`，
> 或執行 `python build.py` 自行打包成可攜資料夾（`dist\錄音轉文字\`，內含 `錄音轉文字.exe`）。
> 語音模型不在程式內，第一次開啟時程式會引導下載。

## 一、可攜資料夾的內容（約 0.4 GB）

```
錄音轉文字\
  錄音轉文字.exe       ← 雙擊執行
  _internal\          ← 程式執行環境（不要動）
  情境說明.txt         ← 一句話描述你的會議類型，提升辨識與找詞準確度（見第九節）
  對照表.範例.tsv      ← 對照表範例；第一次使用時自動複製成 對照表.tsv
  對照表.tsv           ← 你的專有名詞對照表（自動產生，可用記事本編輯）
  設定.json            ← 記住上次的選擇（自動產生）
  README.md           ← 本說明
```

- 整個資料夾複製到別台電腦或隨身碟就能用，**不需要安裝 Python**。
- **語音模型不在資料夾裡**：每台電腦第一次使用時下載一次（見第三節），之後一直留在那台電腦上。

## 二、使用步驟

1. 雙擊 `錄音轉文字.exe`。第一次使用會先跳出「下載語音模型」視窗（見第三節）。
2. 選擇**音檔**（m4a、mp3、wav、mp4 等），選擇**輸出資料夾**。
3. **會議名稱**：預設帶入音檔檔名，可以改。輸出的檔名都以它開頭。
4. **特別整理的主題**（選填）：例如「採購流程」。有填的話會另外產出一份專題整理。
5. 確認「設定」區的三個選項：**AI**、**語音模型**、**語言**（見第四～六節）。
6. 按 **① 開始辨識**。
   - 進度條會顯示已辨識時間與預估剩餘時間。
   - 中途可以按「取消」或直接關閉程式。下次用**同一個會議名稱**再按「① 開始辨識」，會從中斷處接著跑。
7. 辨識完成後，會自動開啟 **② 校正專有名詞** 畫面：
   - 共用對照表裡的詞會先自動替換。
   - 選定的 AI 會列出疑似辨識錯誤的人名、公司名、專有名詞（約需數分鐘）。
   - 點選一項，下方會顯示出現的句子。可以：
     - 按「▶ 播放原音」聽該時間點前後約 12 秒的錄音；
     - 填「改為」，選「替換／待確認／不改」，按「更新選取項目」；
     - 勾選「加入共用對照表」，下次辨識別的錄音會自動套用。
   - **一次多選**：按住 Ctrl（逐一點選）或 Shift（連續範圍）選多個詞，填一次「改為」按「更新選取項目」，就全部改成同一個寫法。
     適合同一個人名被辨識成好幾種寫法的情況。多選時下方會列出每個詞的第一句，方便比對。
   - **替換與待確認的差別**：填了「改為」按更新，就會自動設為「替換」；「改為」留空才是「待確認」。
     待確認的詞不會替換，會列在待確認清單（`<會議名稱>_待確認.md`）。
   - 表格裡沒有的錯字，可以按「＋手動新增」；多個錯誤寫法用頓號或逗號分隔，可一次改成同一個正確寫法。
   - 寫法本來就正確的詞選「不改」，產生會議記錄時就不會加（?）；再勾「加入清單」會記進 **已知名詞**，以後不會再被列為疑問詞。
   - 全部確認後，按 **套用並存檔**。若還有待確認的詞，存檔前會提醒。
8. 按 **③ 產生會議記錄**（存檔後會詢問是否直接進行），約需數分鐘。
   - 如果這份逐字稿已經產生過會議記錄，會先詢問要不要再產生一份新版。新版另存，不覆蓋舊檔，可用來比較兩個 AI 的寫法。
9. 打開產出的會議記錄 md，對照同資料夾的「**<會議名稱>_待確認.md**」修改，可以用記事本或 VS Code。
   會議記錄的架構：會議資訊表（日期、地點、主持人、記錄人、出席人員；聽不出來的留空請自行填寫）→ 重點摘要 → 各議題（背景／討論／決議／待辦）→ 未決事項 → 待辦追蹤表。
10. 改完 md 後，按 **重新產生 PDF**。md 裡的錄音時間點（例如「（00:12:47–00:13:05）」）方便回查錄音，PDF 上不會顯示。
11. 按 **從我的修改學習**：程式比對 AI 原稿和你改好的 md，列出你改過的詞，勾選加入已知名詞或對照表，下一場會議就不必再改同樣的錯。
    - 所有項目預設「略過」，只把人名、公司名、地名、專有名詞的寫法校正改成加入。
    - 數字、日期、時間、金額的修改，以及純粹補上的文字，不會列出（那是內容修訂，不該變成替換規則）。
    - 「提醒」欄標「需確認」的，是抓不到完整詞的項目，請先把原寫法、改為修正成完整的詞再加入。

## 三、語音模型

### 第一次使用：下載

程式找不到模型時，會自動跳出「下載語音模型」視窗；之後也可以按「下載模型…」再下載其他模型。

| 模型 | 大小 | 說明 |
|---|---|---|
| **large-v3-turbo**（建議） | 1.6 GB | 一般會議記錄用這個。準確度接近 large-v3，速度快一倍以上。 |
| small | 0.5 GB | 最快，但中文人名、公司名、專有名詞錯字明顯較多。適合快速了解大概內容。 |
| large-v3 | 3.1 GB | 最準，但速度約為 turbo 的一半以下。適合重要會議或錄音品質差時。建議記憶體 8 GB 以上。 |

- 參考速度（i3-4160 舊辦公電腦）：3 小時的錄音用 turbo 約需 4.3 小時。較新的電腦會快一些。
- 下載中斷或按取消後，再按一次下載，會從中斷處接著下載。

### 模型存放位置

程式依序在下列位置找模型：

1. **這台電腦**：`C:\Users\<帳號>\AppData\Local\錄音轉文字\models\`。下載的模型都存在這裡。
2. **程式資料夾**：`錄音轉文字\models\`。要到沒有網路的電腦使用時，把模型資料夾複製到這裡，跟程式一起帶走。
3. **自選資料夾**：按「選擇模型資料夾…」，可以指向任何位置（例如網路磁碟）。

模型資料夾裡必須有：`model.bin`、`config.json`、`tokenizer.json`、`vocabulary.json`（或 `vocabulary.txt`）。缺檔時程式會提示缺哪些。

其他 faster-whisper 格式的模型也可以用，可到 Hugging Face（huggingface.co）搜尋「faster-whisper」下載整個資料夾。

## 四、語言

| 選項 | 說明 |
|---|---|
| 中文（繁體輸出） | 預設。輸出繁體中文；中文夾雜的英文術語會保留。 |
| 英文、日文 | 整場會議講英文或日文時使用。 |
| 自動偵測 | 依錄音開頭判斷語言，整場當成同一種語言。 |
| 多語混合 | 每一段各自判斷語言，適合多種語言輪流講的會議。比較慢，短句容易判錯。 |

- 不需要另外的「語言包」：同一個模型就涵蓋約 99 種語言。
- 只有中文會做簡轉繁。

## 五、AI（Claude Code／Codex）

在「設定」區的 AI 下拉選單選擇，程式會記住上次的選擇。紀錄區會顯示「本次使用：…」，待確認清單（`_待確認.md`）也會註明由哪一個 AI 整理。

**哪些資料會送給 AI**：語音辨識在本機執行，**錄音檔不會送出**。送給你選定的 AI（Claude Code 或 Codex）的是文字：

| 步驟 | 送出的內容 |
|---|---|
| ② 找疑問詞 | 校正前的逐字稿、情境說明（全部行）、已知名詞（含說明與常被誤寫成） |
| ③ 產生會議記錄／專題 | 校正後的逐字稿、情境說明（全部行）、已知名詞（含說明）、本次確認與待確認的詞 |

情境說明與已知名詞若含公司或個人資料，請確認可以交給該 AI 服務處理。

| 按鈕 | 作用 |
|---|---|
| 登入帳號 | 開一個視窗執行登入，會跳出瀏覽器網頁。Claude Code 已登入時，可在視窗中輸入 `/login` 切換帳號，完成後輸入 `/exit` 離開。 |
| 查看用量 | 用瀏覽器開啟該 AI 的用量頁面。 |
| 安裝說明 | 顯示安裝指令，可複製。 |

### 計費

- 程式一律走你的**訂閱帳號**：Claude Code 用 claude.ai 帳號，Codex 用 ChatGPT 帳號。
- 呼叫時會刻意移除 `ANTHROPIC_API_KEY`／`OPENAI_API_KEY` 環境變數，不會改走 API 另外計費。
- 一場 3 小時的會議約 8 萬字，每次找詞、寫記錄都會用掉不少額度。

### 遇到使用上限

- 介面上方會出現**紅色提示列**，寫明「預計幾點恢復（約幾小時幾分後）」，並跳出視窗。
- 如果另一個 AI 有安裝，可以選擇「改用另一個 AI 立即重試」。
- AI 的錯誤訊息沒有提供恢復時間時，會顯示「恢復時間不明」，請按「查看用量」到網頁上查看。
- 已完成的步驟（辨識、校正）都已存檔，恢復後再按一次即可，不會白做。

## 六、換電腦：安裝 AI 命令列工具（只需做一次）

**不需要 VS Code。** 兩個 AI 至少裝一個；沒裝的話，程式仍可以辨識、用對照表與「＋手動新增」校正、重新產生 PDF。

### Claude Code

1. （若沒有）安裝 **Git for Windows**：https://git-scm.com
2. 開 PowerShell，執行：

   ```powershell
   irm https://claude.ai/install.ps1 | iex
   ```

   或已有 Node.js 18 以上時，改用：

   ```powershell
   npm install -g @anthropic-ai/claude-code
   ```

3. 關掉 PowerShell 再重開，在程式中按「登入帳號」（或在 PowerShell 輸入 `claude`），用 claude.ai 帳號登入。
4. 更新：執行 `claude update`；若失敗，改用：

   ```powershell
   npm install -g @anthropic-ai/claude-code@latest
   ```

### Codex

1. 安裝 **Node.js** 18 以上：https://nodejs.org（選 LTS 版）
2. 開 PowerShell，執行：

   ```powershell
   npm install -g @openai/codex
   ```

3. 在程式中按「登入帳號」（或在 PowerShell 輸入 `codex login`），用 ChatGPT 帳號登入（Plus 以上方案）。
4. 更新：再執行一次安裝指令即可。

裝好後，在程式中切換到該 AI，狀態會顯示「● 已安裝」。若沒有顯示，請重新開啟程式。

## 七、輸出的檔案

| 檔案 | 說明 |
|---|---|
| `<會議名稱>_逐字稿.txt` | 校正後的逐字稿，每行附 `[時:分:秒]` |
| `<會議名稱>_會議記錄.md` 和 `.pdf` | 正式會議記錄（PDF 不顯示錄音時間點） |
| `<會議名稱>_待確認.md` | 給整理者核對：辨識說明、標了（?）的詞、需要回查錄音的地方（不轉 PDF） |
| `<會議名稱>_<主題>_專題整理.md` 和 `.pdf` | 有填主題時才產出 |
| `_工作檔\<會議名稱>\` | 中間檔：16k 音檔、原始辨識結果、校正紀錄、進度、會議記錄的 AI 原稿 |

- **不覆蓋**：輸出資料夾已有同名檔時，會另存成 `(2)`、`(3)`…
- 「重新產生 PDF」也不覆蓋：舊 PDF 保留，新版另存 `(2)`、`(3)`…
- AI 的回覆格式不對（例如沒有分隔正式記錄與待確認清單）時，不產生 PDF，日誌會提示；完整回覆存在 `_工作檔\<會議名稱>\會議記錄_AI回覆.md`。
- `_工作檔` 裡的音檔較大（3 小時約 330 MB）。整份會議記錄確定後，可以自行移到別處或刪除。刪除後就無法續跑或播放原音。

## 八、共用對照表（對照表.tsv）

- 第一次使用時，程式會把 `對照表.範例.tsv` 複製成 `對照表.tsv`，之後都編輯 `對照表.tsv`。
- 每行一筆，格式為「`原辨識<Tab鍵>校正為`」。`#` 開頭的是註解。
- 程式每次辨識完都會自動套用。校正畫面勾選「加入共用對照表」的詞，會加在檔案最後。
- 可以用記事本直接編輯，存檔編碼請用 UTF-8。
- 換電腦時記得把這個檔一起帶走，累積的詞才不會不見。
- 替換是「看到就換」。太短或太常見的詞不要放進來，以免誤換。

## 九、情境說明（情境說明.txt）

**第一行**用一句話描述你的會議類型，程式會放進語音辨識提示與 AI 找詞提示，讓專有名詞辨識得更準。
**第二行起**可寫背景說明（本公司是誰、相關公司的關係、常見角色），給找疑問詞與寫會議記錄的 AI 參考（不放進語音辨識提示）。例如：

```
一場會計師事務所的週會，討論稅務申報、查帳與客戶進度
本公司是「範例會計師事務所」，文中的「我們」「我方」指本公司。
「大華公司」是主要客戶，聯絡窗口是王經理。
```

- `#` 開頭的行是註解。可參考 `情境說明.範例.txt`。
- 沒有這個檔案時，使用通用說明「一場公司內部會議」。

### 已知名詞（已知名詞.txt）

寫法確定正確的人名、公司名、產品名、地名。一行一筆：`名詞｜說明｜常被誤寫成`，後兩欄可省略（`#` 開頭為註解）。

```
王小明｜業務部經理｜王曉明、黃小明
範例股份有限公司｜主要客戶
```

- AI 找疑問詞時不會列出這些詞；產生會議記錄時視為正確寫法，不加（?）。
- 「說明」會交給 AI，讓它知道這個人或公司的角色。
- 「常被誤寫成」會像對照表一樣，辨識完自動替換成正確寫法。
- 主畫面按「**編輯已知名詞**」用記事本開啟；「**從我的修改學習**」與校正畫面選「不改」並勾「加入清單」也會加進來。
- 第一次使用時，程式會把 `已知名詞.範例.txt` 複製成 `已知名詞.txt`。

## 十、環境檢測（換電腦時可先做）

在可攜資料夾開 PowerShell，執行：

```powershell
.\錄音轉文字.exe --檢測 "某個短音檔.m4a" "C:\暫存\檢測"
```

- 會依序測試辨識、AI（兩個都測）、轉 PDF。
- 結果寫在 `C:\暫存\檢測\環境檢測.log`，最後一行出現「全部完成」就表示正常。
- 要先有語音模型：請先開啟程式下載一次。

## 十一、從原始碼執行／自行打包

需要 Windows 與 Python 3.10 以上。

```powershell
git clone https://github.com/jaguarhook-lab/meeting-transcriber-zh.git
cd meeting-transcriber-zh
python -m pip install -r requirements.txt
python app.py            # 直接執行
python build.py          # 打包成可攜資料夾 dist\錄音轉文字\（會帶入本機的對照表、情境說明、已知名詞，分享給別人前請先確認內容）
```

| 檔案 | 作用 |
|---|---|
| `app.py` | 圖形介面與流程 |
| `asr.py` | 語音辨識、模型尋找與下載、語言 |
| `ai_engines.py` | Claude Code／Codex 呼叫、登入、使用上限判斷 |
| `terms.py` | 對照表、專有名詞校正 |
| `learn.py` | 比對 AI 原稿與修改後的記錄（從我的修改學習） |
| `report.py` | 會議記錄與專題的提示詞 |
| `pdf.py` | Markdown 轉 PDF（PyMuPDF） |
| `common.py` | 路徑、設定、不覆蓋的檔名 |
| `build.py` | PyInstaller 打包（先備份可攜版的對照表） |
