# 已知名詞：寫法確定正確的人名、公司名、產品、地名等。「#」開頭的行是註解。
# 格式：一行一筆「名詞｜說明｜常被誤寫成」，後兩欄可省略；誤寫有多個時用頓號分隔。
#   名詞：正確寫法。AI 找疑問詞時不列，產生會議記錄時不加（?）。
#   說明：職稱、角色、公司關係等，給 AI 判斷「指的是誰」。
#   常被誤寫成：語音辨識常見的錯字，辨識完自動替換成正確寫法。
# 可直接用記事本編輯，或用程式的「從我的修改學習」、校正畫面「不改＋加入清單」加入。
# 範例（把開頭的「# 」刪掉就會生效，請改成自己公司的名詞）：
# 王小明｜業務部經理｜王曉明、黃小明
# 範例股份有限公司｜主要客戶
# 中山路｜本公司地址
